# StudyMate — Student Study Planner SaaS 🎓

A beginner-friendly student mini project made with **HTML, CSS, and JavaScript**. It helps students manage study tasks, build a weekly timetable, track progress, save exam reminders, and view rule-based study recommendations.

## ✨ Introduction

StudyMate is a simple, responsive web application that puts common study-planning tools in one place. It is designed as a front-end prototype for a Software as a Service (SaaS) idea: users access the tool through a browser rather than installing a desktop application.

> **Important:** This ZIP is a front-end demo, not a production SaaS service. Data is stored locally in the current browser with `localStorage`. There is no account system, cloud database, real AI connection, or push/email notification service.

## 🚀 Features

- **Task management:** Add and delete tasks, choose a subject, due date, priority, and estimated study time.
- **Study timetable:** Add weekly sessions by day and time.
- **Progress tracking:** See task totals, completed tasks, and completion percentage.
- **Exam reminders:** Save exam/deadline dates and see a countdown inside the app.
- **Study recommendations:** Get simple rule-based suggestions based on pending tasks, priorities, overdue tasks, upcoming exams, and timetable entries.
- **Responsive design:** Works on desktop, tablet, and mobile screens.
- **Local persistence:** Tasks and plans remain in the same browser after refresh.

## 🧰 Technologies

- HTML5 — page structure
- CSS3 — layout, responsive design, styling
- Vanilla JavaScript — interactivity and application logic
- Browser `localStorage` — local data persistence
- GitHub Pages — optional static hosting

## ▶️ Run the project

1. Download and extract the ZIP file.
2. Open the extracted folder.
3. Double-click `index.html` to open it in a modern browser.
4. Add a task, timetable session, or exam reminder.
5. Refresh the page to check that the browser has saved your data.

No installation or build command is required.

## 🌐 Publish using GitHub Pages

1. Create a GitHub repository, for example `student-study-planner-saas`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. The website URL will appear in the Pages settings.

GitHub Pages hosts static files only. It does not provide a secure backend or shared user database.

## 🧭 How to use

1. **Add a task:** Enter a title and optionally a subject and due date. Choose priority and estimated minutes.
2. **Complete a task:** Tick the checkbox beside the task. Your progress percentage updates.
3. **Filter tasks:** Choose all, to do, or completed.
4. **Plan a study session:** Select a day, time, and subject/activity.
5. **Add an exam:** Enter an exam or deadline name and date.
6. **Use recommendations:** Read the suggestion cards and apply the tips that suit your schedule.

## ☁️ SaaS model explanation

A production SaaS version would usually include:
- Secure user registration and login
- A hosted backend API
- A cloud database with separate data for each user
- Reliable scheduled notifications
- Access control, backups, privacy controls, and monitoring
- An optional free plan and paid subscription tier

Those services are **not included** in this beginner front-end project.

## ✅ Advantages

- Easy for beginners to understand and modify
- Helps students organize tasks and deadlines
- Progress feedback can encourage consistency
- Responsive interface for different screen sizes
- No paid dependencies needed to run locally
- Good foundation for learning JavaScript and GitHub

## ⚠️ Disadvantages / limitations

- Data is only stored in the current browser and is not synced across devices
- Clearing browser site data may erase the saved planner data
- No login or cloud backup
- Exam reminders appear in the app; they do not send push notifications, SMS, or emails
- Study recommendations use simple rules; they are not generated by an AI model
- A production SaaS application needs backend development, security testing, and hosting
